01. about

From writing the app
to guarding its data.

I started my career at Braindigit as an ASP.NET developer, building web applications with ADO.NET, jQuery and AJAX. Working that close to the data drew me to the database itself.

Since 2014 I've been the team's SQL Server Database Administrator. I look after backup and restore, database development and the day-to-day health of production systems. I've also worked with MongoDB, and to a lesser extent MySQL and PostgreSQL.

I'm still a developer too: I build full-stack apps with .NET Core on the back end and React on the front end. Because I work on both sides, I know how applications use the database, not only how the server runs.

I hold a B.E. in Computer Engineering and I'm expanding into Microsoft Azure. I also write about programming on my blogs.
